# Harbor

Harbor is a sample sales workspace for finding people, keeping lists, and planning outreach. LinkedIn is the first channel. The workspace starts with **10,000 credits**.

Searching, saving, and drafting notes are free. Credits are spent only when you reveal:

- a work email (1 credit)
- a direct phone (5 credits)
- company funding and technology (2 credits)

People and companies in the app are fictional. Integrations are demo connections: Harbor explains the approval step and does not ask for a password, scrape LinkedIn, or send messages for you.

## Run it

```bash
npm install
npm run dev
```

Open the URL Vite prints (port 5173). Your credits, lists, and sequences stay in this browser.

```bash
npm run build
```
